Jira Service Management (JSM) – Practical Infrastructure Management

Click the blue Create button at the top of the screen and set the Issue Type to Incident.

For the sake of this example, we’ll use the scenario:

Summary: "User reports clicking a suspicious link and password no longer working."

Description: "User received an email looking like an internal HR memo. Input credentials. System now showing multiple failed login attempts on endpoint PC-04."

Set the Priority to High or Highest. Click Create.

Agent Workflow

On your left navigation sidebar, click Queues. Open the All Open queue, click on your new incident ticket and assign it to yourself.

We can now move the status from To Do (or Open) to In Progress because we would be working to resolve this issue.

We can also add an Internal Comment (hidden from the end-user) documenting your security steps. For example:

"Isolating user's endpoint from the network via firewall rules. Initiating an Active Directory password reset and terminating all active sessions to minimize risk."

Lastly, move the ticket to Resolved.
