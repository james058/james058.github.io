Directory Scanning

We check for directories using gobuster: 


gobuster dir -u http://monitorsfour.htb \
-w /usr/share/wordlists/seclists/

The /controllers route returned a 403 forbidden response. The /user endpoint looked more interesting.

We added a token parameter: http://monitorsfour.htb/user?token=0

The password values appeared to be hashes, so they were checked against CrackStation.

Admin Login

After logging in successfully, no immediate attack vector was found, so virtual host enumeration was performed.

VHost Enumeration


ffuf -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-5000.txt:FUZZ \
-u http://monitorsfour.htb \
-H 'Host: FUZZ.monitorsfour.htb'

The valid subdomain discovered was: cacti.monitorsfour.htb

Privilege Escalation (CVE-2025-9074)

The shell was inside a Docker container, requiring container escape to access the host filesystem. we weren’t able to get a connection but based on the error, at least we were able to get an IP address: 192.168.65.254 >host.docker.internal points to 192.168.65.254 but we couldn’t get get a connection so we can check other IP addresses in the subnet using the following script: 


for i in $(seq 1 254); do
(
curl -s --connect-timeout 1 \
http://192.168.65.$i:2375/version \
2>/dev/null | grep -q "ApiVersion" \
&& echo "192.168.65.$i:2375 OPEN"
) &
done
wait

we get a hit. The Docker API is open on 192.168.65.7.
